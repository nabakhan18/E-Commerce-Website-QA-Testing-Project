# Shopping Cart Testing Checklist

## Add Product

- [ ] Add to Cart button works
- [ ] Product is added to Cart
- [ ] Correct product name is displayed
- [ ] Correct price is displayed
- [ ] Cart count updates

## Quantity

- [ ] Quantity can be increased
- [ ] Quantity can be decreased
- [ ] Quantity cannot become invalid
- [ ] Price updates after quantity change
- [ ] Total updates correctly

## Remove

- [ ] Remove button works
- [ ] Product is removed
- [ ] Cart total updates
- [ ] Cart count updates

## Cart Validation

- [ ] Multiple products can be added
- [ ] Different quantities work correctly
- [ ] Empty Cart message is displayed
- [ ] Cart does not display incorrect products
