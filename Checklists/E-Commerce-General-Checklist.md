# E-Commerce General Testing Checklist

## Application Access

- [ ] Website loads successfully
- [ ] Homepage opens without errors
- [ ] No broken page is displayed
- [ ] Website URL is accessible
- [ ] Main navigation is visible

## Navigation

- [ ] Home link works
- [ ] Products link works
- [ ] Login link works
- [ ] Registration link works
- [ ] Cart link works
- [ ] Checkout link works
- [ ] Browser Back button works
- [ ] No broken links are present

## Functional

- [ ] Main features work as expected
- [ ] Buttons perform the correct action
- [ ] Forms accept valid data
- [ ] Invalid data is handled correctly
- [ ] Required fields are validated
- [ ] Error messages are displayed
- [ ] Success messages are displayed

## Product

- [ ] Products are displayed
- [ ] Product names are correct
- [ ] Product prices are correct
- [ ] Product images load
- [ ] Product details open
- [ ] Add to Cart works

## Cart

- [ ] Product can be added
- [ ] Product appears in Cart
- [ ] Quantity can be changed
- [ ] Product can be removed
- [ ] Cart total is correct
- [ ] Empty Cart is handled correctly

## Checkout

- [ ] Checkout page opens
- [ ] Required fields are displayed
- [ ] Required-field validation works
- [ ] Valid information is accepted
- [ ] Invalid information is rejected
- [ ] Order summary is displayed
- [ ] Total price is correct
- [ ] Order can be submitted
- [ ] Confirmation is displayed
