# Search Testing Checklist

- [ ] Search field is visible
- [ ] Search button/icon is visible
- [ ] Existing product can be searched
- [ ] Relevant results are displayed
- [ ] Non-existing product is handled
- [ ] "No results" message is displayed
- [ ] Empty search is handled
- [ ] Partial product name works
- [ ] Search is case-insensitive if required
- [ ] Special characters are handled
- [ ] Search results are relevant
- [ ] Search does not crash the application
