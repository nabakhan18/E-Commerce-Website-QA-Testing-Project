# UI Testing Checklist

## Layout

- [ ] Page layout is consistent
- [ ] Elements are properly aligned
- [ ] No overlapping elements
- [ ] No text is cut off
- [ ] Images fit correctly
- [ ] Buttons are properly positioned

## Typography

- [ ] Text is readable
- [ ] Font size is appropriate
- [ ] Headings are clear
- [ ] Labels are understandable

## Buttons

- [ ] Buttons are visible
- [ ] Buttons have meaningful labels
- [ ] Buttons are clickable
- [ ] Hover state works if applicable
- [ ] Disabled state is clear if applicable

## Forms

- [ ] Input fields are aligned
- [ ] Labels are visible
- [ ] Placeholder text is clear
- [ ] Error messages are visible
- [ ] Success messages are visible

## Responsive

- [ ] Desktop layout works
- [ ] Tablet layout works
- [ ] Mobile layout works
- [ ] Navigation adapts correctly
- [ ] Images resize correctly
