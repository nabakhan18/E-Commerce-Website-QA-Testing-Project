# Login Module — Test Plan

## Objective

To verify that users can securely and correctly log in and log out
of the E-Commerce application.

## Scope

### In Scope

- Login page
- Email validation
- Password validation
- Valid login
- Invalid login
- Empty fields
- Password visibility
- Logout

### Out of Scope

- Advanced security penetration testing
- Server-side authentication implementation
- Third-party authentication services

## Testing Types

- Functional Testing
- Positive Testing
- Negative Testing
- UI Testing
- Regression Testing

## Test Scenarios

1. Login with valid credentials.
2. Login with invalid email.
3. Login with invalid password.
4. Login with both invalid credentials.
5. Login with empty email.
6. Login with empty password.
7. Login with both fields empty.
8. Verify password visibility.
9. Verify error messages.
10. Verify successful logout.

## Entry Criteria

- Login page is available.
- Test account exists.
- Test environment is accessible.

## Exit Criteria

- All login test cases are executed.
- Critical login defects are resolved.
- Regression testing is completed.

## Deliverables

- Login test cases
- Bug reports
- Test execution results
