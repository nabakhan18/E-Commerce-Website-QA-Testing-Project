# BUG-001 — Invalid Password Error Not Displayed

## Bug Type
Functional Bug

## Module
Login

## Severity
Medium

## Priority
High

## Environment
- Browser: Google Chrome
- OS: Windows 11
- Application: E-Commerce Website

## Preconditions
User has a registered account.

## Steps to Reproduce
1. Open the E-Commerce website.
2. Navigate to Login.
3. Enter a valid registered email.
4. Enter an incorrect password.
5. Click Login.

## Expected Result
An appropriate error message should be displayed and the user should remain logged out.

## Actual Result
The page does not clearly display an error message.
