# Checkout Testing Checklist

## Checkout Page

- [ ] Checkout page opens
- [ ] Order summary is displayed
- [ ] Customer information fields are visible
- [ ] Required fields are identified
- [ ] Place Order button is visible

## Customer Information

- [ ] Valid name is accepted
- [ ] Valid email is accepted
- [ ] Valid address is accepted
- [ ] Valid phone number is accepted
- [ ] Invalid email is rejected
- [ ] Invalid phone number is handled
- [ ] Empty required fields are validated

## Order Summary

- [ ] Product name is correct
- [ ] Product quantity is correct
- [ ] Product price is correct
- [ ] Subtotal is correct
- [ ] Additional charges are correct if applicable
- [ ] Final total is correct

## Order

- [ ] Valid order can be submitted
- [ ] Invalid order cannot be submitted
- [ ] Confirmation message is displayed
- [ ] Order details are displayed after submission
