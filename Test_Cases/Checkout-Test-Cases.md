

# E-Commerce Checkout Test Cases

## TC-CHECKOUT-001 — Checkout with valid information

### Steps
1. Add a product to Cart.
2. Open Cart.
3. Click Checkout.
4. Enter valid customer information.
5. Select available payment method.
6. Submit order.

### Expected Result
Order should be successfully placed.

### Status
Not Executed



# TC-CHECKOUT-002 — Checkout with empty required fields

### Steps

### Expected Result
Validation messages should be displayed.

Not Executed
