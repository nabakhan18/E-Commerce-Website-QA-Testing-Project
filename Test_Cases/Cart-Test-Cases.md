# E-Commerce Cart Test Cases

## TC-CART-001 — Add product to cart

### Steps
1. Open a product.
2. Click Add to Cart.
3. Open Cart.

### Expected Result
Selected product should appear in the cart.

### Status
Not Executed



# TC-CART-002 — Remove product from cart

### Steps
1. Add a product to cart.
2. Open Cart.
3. Click Remove.

### Expected Result
Product should be removed from the cart.

### Status
Not Executed
